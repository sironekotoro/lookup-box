LookupBox

参照リストを、ブラウザからすぐ検索・コピー。

現在のLookupBox
Google OAuthで接続し、複数のGoogle Sheetを検索リストとして登録できます。通常版ではGAS URLやAPI Tokenの設定は不要です。

使い方

  1. LookupBoxをインストールし、設定画面で「Googleに接続」を押します。
  2. 1行目を列名にしたGoogle SheetのURLを貼り、「Sheetを確認」を押します。
  3. 検索対象のタブと Key / Value 列を選び、「登録して同期」を押します。
  4. 必要なら別のGoogle Sheetも同じ手順で追加します。リスト名はSpreadsheet名から自動で決まります。
  5. ポップアップで全リストを横断検索するか、リストを切り替えて検索します。
  6. Sheetを更新したら、ポップアップの「再同期」で登録済みリストをまとめて更新します。

例

NameCode
AppleAAPL
MicrosoftMSFT

「Apple」でも「AAPL」でも同じ行を検索できます。

複数リスト

複数のSpreadsheetやタブを登録できます。同じSpreadsheetから複数リストを作る場合は、Spreadsheet名 / Sheet名 のように自動で区別します。

権限と接続

標準のChrome / FirefoxパッケージはGoogle Sheets APIへ直接接続します。旧ゲートウェイ用のホスト権限や設定項目は配布パッケージから削除しています。

対応ブラウザ

同一コードベースからChrome / Firefox向けパッケージをGitHub Actionsで生成します。
