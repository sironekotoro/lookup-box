# Store listing draft

This is working copy for Chrome Web Store / Firefox Add-ons submission text. Update it again after the final public OAuth flow is frozen.

## Product name

LookupBox

## Short summary

参照リストを、ブラウザからすぐ検索・コピー。

## Single purpose

LookupBox lets a user register reference lists backed by Google Sheets, synchronize the selected key/value columns into local browser storage, search those cached lists from a browser popup, and copy values with one click.

LookupBox does not edit Google Sheets and does not modify web pages.

## Description (Japanese draft)

LookupBox は、Google Sheets に置いた参照リストをブラウザからすばやく検索・コピーするための拡張機能です。

Google アカウントに接続し、利用したい Spreadsheet / Sheet / Key列 / Value列を登録すると、LookupBox が必要なデータをブラウザ内に同期します。以後はポップアップからインクリメンタル検索し、必要な値をワンクリックでコピーできます。

主な機能:

- 複数の Google Sheet リストを登録
- Spreadsheet名からリスト名を自動生成
- Key / Value の双方から検索
- 全リスト横断検索またはリスト切り替え
- ワンクリックコピー
- 手動再同期
- Sheet上の表示済み文字列を利用し、先頭ゼロ等の表示形式を保持

LookupBox は検索語を開発者のサーバーへ送信しません。同期したリストデータはブラウザの拡張機能用ローカルストレージに保存されます。

## Chrome Web Store permission justification

### storage

Stores registered list definitions and synchronized rows locally in the browser. This is required for fast popup search without contacting Google Sheets for every search keystroke.

### identity

Used only for Google authorization so LookupBox can access the Google Sheet(s) required for its primary function.

### sheets.googleapis.com host access

Used only to call Google Sheets API endpoints for Spreadsheet metadata and formatted cell values. LookupBox does not request Google Sheets write access.

## Data handling disclosure draft

- Popup search terms: processed locally; not sent to the developer.
- Registered list configuration: stored locally in extension storage.
- Synchronized lookup rows: stored locally in extension storage.
- OAuth access tokens: used only for direct Google API communication; not sent to a LookupBox developer-operated server.
- Analytics/telemetry: none in the current public candidate.
- Advertising: none.
- Sale of user data: none.

## Firefox AMO reviewer notes draft

LookupBox is a WXT + React browser extension. The repository is public and includes the build configuration and source code.

The add-on's single purpose is local lookup/search over user-authorized Google Sheet reference lists.

Network communication is limited to Google authorization and Google API endpoints required to retrieve the configured Sheet data. Popup searches run locally against browser storage and are not transmitted to a third-party search service.

The production Firefox OAuth design is still being hardened. Do not submit this text unchanged while the development implicit bridge is still present.

If AMO requests source code because the distributed bundle is minified, submit the reproducible source package generated by WXT and include exact Node/npm/build commands in reviewer notes.
